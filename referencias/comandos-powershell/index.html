    Comandos PowerShell

    Referencia para TechStore-Proyecto (ProyectoMS2026) en DEV: Gateway 7091, Eureka 7081, Config 7071. Todas las pruebas de API entran por Gateway.

    Infraestructura DEV

    # Config Server
Invoke-RestMethod -Uri "http://localhost:7071/actuator/health"
Invoke-RestMethod -Uri "http://localhost:7071/producto/dev"

# Eureka (registry-server)
Invoke-RestMethod -Uri "http://localhost:7081"
Invoke-RestMethod -Uri "http://localhost:7081/eureka/apps"

    Health del Gateway

    Invoke-RestMethod -Method Get -Uri "http://localhost:7091/actuator/health"
Invoke-RestMethod -Uri "http://localhost:7091/actuator/prometheus"

    Rutas públicas vía Gateway

    # catalogo
Invoke-RestMethod -Uri "http://localhost:7091/api/v1/categorias"

# producto
Invoke-RestMethod -Uri "http://localhost:7091/api/v1/productos"

# balanceo (S04) — varias llamadas muestran puertos distintos
1..10 | ForEach-Object { Invoke-RestMethod -Uri "http://localhost:7091/api/v1/producto/instancia" }

    Login (auth)

    $body = @{
  username = "admin"
  password = "admin123"
} | ConvertTo-Json

$response = Invoke-RestMethod `
  -Method Post `
  -Uri "http://localhost:7091/auth/login" `
  -ContentType "application/json" `
  -Body $body

$token = $response.accessToken
Write-Host $token

    Consumir rutas protegidas

    $headers = @{ Authorization = "Bearer $token" }

# producto
Invoke-RestMethod -Uri "http://localhost:7091/api/v1/productos" -Headers $headers

# pedido
Invoke-RestMethod -Uri "http://localhost:7091/api/v1/pedidos" -Headers $headers

# carrito
Invoke-RestMethod -Uri "http://localhost:7091/api/v1/carritos" -Headers $headers

# pago
Invoke-RestMethod -Uri "http://localhost:7091/api/v1/pagos" -Headers $headers

    Levantar BD: docker compose -f services/<ms>/docker-compose-dev.yml up -d. Credenciales: root / root.

    MicroservicioContenedorBase de datosPuerto host
    authmysql-auth-devdb_auth3341
    catalogomysql-catalogo-devdb_catalogo3381
    productomysql-producto-devdb_producto3391
    pedidomysql-pedido-devdb_pedido3401
    pagomysql-pago-devdb_pago3411
    carritomysql-carrito-devdb_carrito3421
     
    # Ejemplo catalogo
docker exec -it mysql-catalogo-dev mysql -uroot -proot db_catalogo

# Ejemplo pedido
docker exec -it mysql-pedido-dev mysql -uroot -proot db_pedido

    Kafka topics

    Levantar Kafka: cd kafka y docker compose up -d (red ms-net debe existir). UI: http://localhost:28085.

    docker exec -it kafka /opt/kafka/bin/kafka-topics.sh --list --bootstrap-server kafka:9092
docker exec -it kafka /opt/kafka/bin/kafka-topics.sh --create --topic pedido-eventos --bootstrap-server kafka:9092 --partitions 1 --replication-factor 1
docker exec -it kafka /opt/kafka/bin/kafka-topics.sh --create --topic pago-eventos --bootstrap-server kafka:9092 --partitions 1 --replication-factor 1
