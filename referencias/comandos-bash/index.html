    Comandos bash macOS/Linux

    Referencia para TechStore-Proyecto (ProyectoMS2026) en DEV: Gateway 7091, Eureka 7081, Config 7071. Todas las pruebas de API entran por Gateway.

    Infraestructura DEV

    # Config Server
curl http://localhost:7071/actuator/health
curl http://localhost:7071/producto/dev

# Eureka (registry-server)
curl http://localhost:7081
curl http://localhost:7081/eureka/apps/CATALOGO

    Health del Gateway

    curl http://localhost:7091/actuator/health
curl http://localhost:7091/actuator/prometheus

    Rutas públicas vía Gateway

    curl http://localhost:7091/api/v1/categorias
curl http://localhost:7091/api/v1/productos

# balanceo (S04)
for i in {1..10}; do curl -s http://localhost:7091/api/v1/producto/instancia; echo; done

    Login (auth)

    response=$(curl -s -X POST "http://localhost:7091/auth/login" \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"admin123"}')

token=$(echo "$response" | jq -r '.accessToken')
echo "$token"

    Consumir rutas protegidas

    curl -H "Authorization: Bearer $token" http://localhost:7091/api/v1/productos
curl -H "Authorization: Bearer $token" http://localhost:7091/api/v1/pedidos
curl -H "Authorization: Bearer $token" http://localhost:7091/api/v1/carritos
curl -H "Authorization: Bearer $token" http://localhost:7091/api/v1/pagos

    MySQL dentro del contenedor

    Levantar BD: docker compose -f services/<ms>/docker-compose-dev.yml up -d. Credenciales: root / root.

    MicroservicioContenedorBase de datosPuerto host
    authmysql-auth-devdb_auth3341
    catalogomysql-catalogo-devdb_catalogo3381
    productomysql-producto-devdb_producto3391
    pedidomysql-pedido-devdb_pedido3401
    pagomysql-pago-devdb_pago3411
    carritomysql-carrito-devdb_carrito3421
     
    docker exec -it mysql-catalogo-dev mysql -uroot -proot db_catalogo
docker exec -it mysql-pedido-dev mysql -uroot -proot db_pedido

    Dentro de MySQL:

    SHOW TABLES;
DESCRIBE categorias;
SELECT * FROM categorias LIMIT 10;
EXIT;

    Kafka topics

    Levantar Kafka: cd kafka && docker compose up -d. UI: http://localhost:28085.

    docker exec -it kafka /opt/kafka/bin/kafka-topics.sh --list --bootstrap-server kafka:9092
docker exec -it kafka /opt/kafka/bin/kafka-topics.sh --create --topic pedido-eventos --bootstrap-server kafka:9092 --partitions 1 --replication-factor 1
docker exec -it kafka /opt/kafka/bin/kafka-topics.sh --create --topic pago-eventos --bootstrap-server kafka:9092 --partitions 1 --replication-factor 1
